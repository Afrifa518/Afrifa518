### About me

I build production software end-to-end. For the last ~4 years I've been the founding CTO of **Kibbutz Pishon Ltd**, an agritech company in Ghana, where I designed and shipped **KPee** — a multi-tenant SaaS platform that runs cooperative banking (savings, loans, shares), a commodity trading marketplace (Edwamanso), double-entry general-ledger accounting, and a role-scoped AI agent system for real agricultural cooperatives.

Every line of code, every architectural decision, every deployment — **one-person engineering team, since day zero.**

I'm now opening up to remote engineering roles so I can keep building at that scope alongside a strong team.
